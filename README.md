🎉 Event Registration System

A simple and responsive Event Registration System built using HTML, CSS, and JavaScript.
This project allows users to register for events and view the list of participants in real-time.

---

📌 Features

- 📝 User Registration Form
- ✅ Form Validation (no empty fields)
- 🚫 Duplicate Email Prevention
- 📊 Dynamic Display of Registered Users
- 🎨 Clean and Responsive UI

---

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
